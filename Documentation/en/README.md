# KLAdaptivePalette

> [English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)

`KLAdaptivePalette` derives a stable palette from the image region visible in a host container. It is a CoreGraphics-only Swift 6 package for iOS 17+ and macOS 14+.
