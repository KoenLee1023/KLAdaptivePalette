# 변경 기록

## 0.1.2

- 분석 결과를 저장하는 메모리 캐시에 용량 제한이 있는 LRU 정책을 적용했습니다.

## 0.1.1

- 단색 이미지의 색을 유지하면서 질감이 있는 무채색 및 유채색 가장자리에서 래스터 색을 정돈하는 처리를 복원했습니다.
- `KLPaletteAnalysisConfiguration`으로 분석 래스터의 크기와 픽셀 수를 제한했습니다.
- `KLPerceptualColor`에 OKLCH 보간 API를 추가했습니다.

## 0.1.0

- 보이는 크롭 팔레트 분석, 결정적 캐시, 테스트, DocC, 데모를 포함한 첫 공개 릴리스입니다.
